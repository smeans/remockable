# remockable

A command-line tool.

## Installation

```sh
npm install -g remockable
```

Or run it once without installing:

```sh
npx remockable hello
```

## Usage

```sh
remockable hello          # -> Hello, world!
remockable hello Ada      # -> Hello, Ada!
remockable --help
remockable --version
```

## Development

```sh
npm install       # install dependencies
npm start         # run the CLI locally
npm test          # run the test suite (node:test)
npm link          # symlink the `remockable` command for local testing
```
